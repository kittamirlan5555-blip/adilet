# scripts/audit/ — верификация и гейты

Единая команда — `python scripts/verify.py {слаг...}|--all` (в корне scripts/):
оркестрирует 71_gates/75/74 (strict) + 76 + корпусные 67/64/69, exit 1 при FAIL.

Поштучно: `71_gates.py` (G1–G6, вкл. синхронность форм), `75_crosscode_verify`
(якоря cross-code по нашим картам; классы RANGE-FIRST и DEPLOY_PENDING §9),
`74_code_freshness_check` (протухшие НГР; корзины hist/wait), `67/64/69` —
корпусные независимые проверки, `a01–a06` — аудиты фаз (a06 — профили source),
`auditlib.py` — общая библиотека.

`rN_*` — рабочие скрипты раундов (r2 — флаги Анары, r3 — закрывающий,
r4 — ночной): исполнены, оставлены для воспроизводимости отчётов.

ВСЕ гейты слепы к смыслу спанов — спот-чек сырого HTML руками обязателен (§6).
