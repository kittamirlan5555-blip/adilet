### PART D · Connectivity — доступность и живость (2026-06-02)

#### Sanity-тест честности пути — ВАЖНО

Отклики 0.0–0.2с были подозрительны (HEAD без тела). Запрос ЗАВЕДОМО несуществующих id вскрыл ДВА режима сети:

| режим | запрос | результат |
|---|---|---|
| холодный (честный) | `GET /rus/docs/K9999999999` (и Z9999…, ZZZZ…) | **HTTP 404**, ~20.3 КБ error-page, без `<title>` |
| холодный (честный) | `GET /rus/docs/K1700000125` (реальный) | **HTTP 200**, **2.03 МБ**, реальный `<title>`/контент |
| под нагрузкой (WAF) | `GET /rus/docs/{ЛЮБОЙ}` вкл. `K9999999999` | **HTTP 200**, единый **~20.8 КБ SPA-shell**, generic `<title>` |

→ Путь МОЖЕТ быть честным (холодный старт: garbage→404, реальный→2 МБ контента), НО после батч-нагрузки adilet/CDN включает WAF и отдаёт одинаковый ~20.8 КБ shell с HTTP 200 на ВСЁ — включая несуществующий id. Проверено: даже после 30с и 110с cooldown + троттлинга garbage и реальный неотличимы (200/20807). **Следовательно через ЭТУ сеть массовая поштучная живость по HTML надёжно НЕ верифицируется** (критерий ТЗ: 200 на garbage → щит «врёт» → форма URL и так гарантирует корректность).

#### Подтверждено живостью (в честном окне)

- garbage `K9999999999 / Z9999999999 / ZZZZZZZZZZ` → **404** (путь различает существование);
- реальные в честном окне → **200 с реальным контентом**: `K1700000125` (2.03 МБ); ранее HEAD-спот-чек 14 топ-чужих → 200.

#### Внутренний Adilet API `85.202.192.66:9096`

Хост ДОСТУПЕН (TCP+HTTP отвечает), но корень и 14 типовых путей (`/`, `/health`, `/api`, `/swagger`, `/rus/docs/{ID}`, `/api/documents/{ID}` …) → **HTTP 404**. Рабочий endpoint без спецификации не обнаружен.

#### Батч всех 424 (411 чужих + 13 наших) — `scripts/39_external_liveness.py`

Прогон (12 потоков): 423/424 «200+title», 1 timeout (при ретрае → 200). НО т.к. WAF-shell тоже отдаёт «200+title», батч доказывает лишь «сервер достижим», НЕ поштучную живость. Мёртвых по статусу (404/5xx) нет — но под WAF-режимом, поэтому НЕ финально. Сырьё → `data/reports/39_liveness.txt`, `_ext_liveness.tsv`.

**Вывод PART D:** инфраструктура достижима (внутр. API-хост; adilet); в честном окне путь корректно различает существование (garbage→404, реальный→2 МБ). Полная поштучная живость 411 чужих актов через эту сеть надёжно НЕ снимается из-за WAF-щита (200-shell на всё). Для финала нужен либо троттленный прогон с «чистого» IP (≤1 req / неск. сек, single-thread, классификация по размеру тела ≫ shell), либо спецификация внутреннего API.
