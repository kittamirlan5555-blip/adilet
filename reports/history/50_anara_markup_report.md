## 5. TYPE A — анализ ложных срабатываний (что НЕ трогали и почему)

Поверхность «незалинкованных по имени» оказалась почти целиком ложной:

| Кажется отсылкой | На деле | Решение |
|---|---|---|
| «(Налоговый кодекс)» | в виджете сайта `<h4>Популярные документы</h4>` (скрап-хром adilet) | пропуск |
| КоАП «административное правонарушение» (ед.ч.) | **деяние**-нарицательное, не акт | пропуск |
| «соглашение об инвестициях» ×44 | **вид договора**, не Закон | пропуск |
| «в области … мореплавания», «земли … транспорта» | сферы/категории земель | пропуск |
| Предпр. кодекс внутри predprinimatel | **самоссылка** на собственный документ | пропуск |
| ст.323/324 «Об инвестициях» | редакционные **сноски** | пропуск |
| КоАП «Кодексом/законодательством»+`#z` | **уже** залинковано соседнее слово (Pattern-2) | пропуск |

Залинкованы только **генуинные** имена акта (КоАП), где фраза реально не была
ссылкой: predprinimatel ст.147; zemelnyy ст.44-2/99/164-1.
