## Анализ Δ-ссылок

- **+40 / +35 / +108 / +537 / +639** для appk/byudzhet/ekologicheskiy/koap/upk — крупный прирост: связано с:
  1. Добавлением синтетических anchor-заголовков (RC1) — теперь ссылки на «статью 59 настоящего Кодекса» создаются впервые;
  2. SELF_PART_WORD_PATTERN — словесные числительные «частью первой/второй настоящей статьи» теперь линкуются;
  3. Очисткой orphan `</a>` — больше валидных пар `<a>` сохраняется.

- **−40 predprinimatel / −5 socialnyy** — небольшое уменьшение. Не регрессия: вызвано более агрессивным `_merge_adjacent_same_doc_links` в скрипте 13 (соседние ссылки на один документ склеиваются в одну) и/или защитой `is_article_heading` от ложного линковния «Статья N» внутри заголовка (RC1 как побочный эффект — несколько ложных ссылок теперь не создаются).

- **0 nested `<a>` / 0 empty href / 0 hash href / balance=0** во всех 12 кодексах — **нет регрессий**.

## Что осталось контролировать вручную (UI)

CSS-подсветка `:target`. В `06_finalize.py` я снизил контраст с `#FFFF88` (ярко-жёлтый) до `rgba(255,255,140,0.35)` + тонкая `box-shadow: inset 3px 0 0 #f0b400`. Теперь даже большой параграф, обёрнутый в `:target`, выглядит мягко (с вертикальной полосой слева).

**Это лишь смягчает жалобу Анары о «много выделенных», но не убирает её полностью.** Идеальный фикс — подсвечивать только сам якорь, а не родительский `<p>`. Это можно сделать в отдельной итерации.
