100 случайных **материальных** законов РК (Z), **без** законов-поправок и **без** пересечений

## 4. Целостность ссылок (независимо из сырого HTML, §6) — по всем 99 DONE

| Проверка | Пилот-2 | (Пилот-1 для сравнения) |
|---|--:|--:|
| nested `<a>` | **0** | 0 |
| висячие `#z` | **0** | 0 |
| escaped-anchor (ссылка как литерал `<a href…>`) | **0** | 9 |
| пустой `href=""` | **0** | 1 |
| text-invariance `_ready==_structured` | 95 точно + 4 безвредных | 86 + 10 |

4 «расхождения» text-invariance безвредны: в `_structured` есть тексты заголовков глав/§ и
пометок «Статья N исключена», которые `_ready` извлекает иначе. Текст статей сохранён,
escaped-anchor=0 подтверждает отсутствие порчи ссылок. Спот-чек 5 случайных DONE — **все PASS**.

## 7. Вывод

На **материальных** законах пайплайн работает: **96/100 полностью корректны** (структура +
