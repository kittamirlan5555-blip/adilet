## 1. Честный статус в `pilot/02_batch_run.py`

`DONE` теперь только если chunk-файл есть, чанков >0 **и** число статей в чанках == числу
`div.article` в структуре. Иначе `UNDER_CHUNK` (не сошлись) / `EMPTY` (0 чанков). Добавлены
колонки `ст/чанк`, секция «Недочанковано» в отчёт. Скелетный режим (`pre,struct,gate`) не задет.

## 2. Фикс `11_structure_html` — раскладка «вариант-B»

**Причина** (диагностировано): у части старых законов каждый блок завёрнут в свой `<div>`
(`article > div > p > b > Статья`), а `flatten_article` смотрит только прямых детей `<article>`
→ 0 `div.article`. Фикс `unwrap_div_layout()`: если прямых маркеров нет, а глубже есть —
развернуть `<div>`-обёртки (плоские раскладки не трогаются).

**Регресс (patched vs HEAD, temp):**
- 43 корпусных кодекса — **байт-в-байт идентичны** (0 диффов);
- 96 DONE пилота-2 — **0 изменений** `div.article`.
→ 100% чисто, фикс влит в `scripts/pipeline/11_structure_html.py` (+60 строк).

## 3. Детект «утратил силу» в `pilot/01_ingest_adilet.py`

Маркер (сравнение Z970000187_ vs Z020000299_): в ШАПКЕ документа (до первой «Статья N.») стоит
`Сноска. Утратил силу Законом/Кодексом РК от <дата>`. Детект по шапке (не по телу — чтобы не ловить
статейные «Статья N. Утратила силу»). Вердикт `REPEALED` → в `codes.json` НЕ регистрируется,
пишется в манифест.

**Проверка на двух:** Z970000187_ (1997) → `REPEALED` ✅; Z020000299_ (2002, действует) → не флагнут ✅.
