# BLOCK 2 — покрытие npa_mapping (каждый акт корпуса)

## Проблема
Внешний аудит: 132 из 295 корпусных актов НЕ имели своего quoted-name ключа в
npa_mapping — корпус их содержит, а сослаться по имени нельзя (в т.ч. «О медиации»,
«О судебно-экспертной деятельности», «Об охране почв», «О техническом регулировании»,
«О профилактике правонарушений»).

Причина: прежний автоген брал имена только из ИЗВЛЕЧЁННЫХ цитат, а не из ВСЕХ актов
реестра. Плюс «покрытым» ошибочно считался акт, чей НГР упомянут ЛЮБЫМ ключом (напр.
descriptive «законодательства о X»), хотя цитата по ИМЕНИ «"Название"» не резолвилась.

## Фикс (`pilot/autogen_npa_full.py`, ключ-центрично)
Для КАЖДОГО акта codes.json: title (полный — из реестра, т.к. codes.json режет до 120
симв и годовые бюджеты становятся неотличимы; чистим «- ИПС "Әділет"») + doc_id →
ключ `"{Название}"`. 03 оборачивает имя, 72 поглощает префикс «Закон* РК» (корп. стандарт).
Это НАШИ акты — title↔НГР верны по построению (мы их ингестили), §5-сверка не нужна.

## Итог
- **npa_mapping: 414 → 643 ключа** (+229 quoted-name ключей корпусных актов).
- **Актов со своим quoted-ключом: 291 / 295.**
- Все 132 ранее-пропущенных (включая ВСЕ названные Анарой) — закрыты.

«О торговом мореплавании»). Детали: `reports/anara2_mapping_unresolved.json`.
