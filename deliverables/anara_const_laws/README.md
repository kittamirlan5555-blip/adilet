# ADILETkz — пакет «Конституционные законы» (для Анары)

Самодостаточный пакет по **9 конституционным законам**, добавленным в корпус. Всё
проверено независимо из сырого HTML (не только гейтами). Дата сборки: 2026-06-22.

## Что сделано (headline, по факту проверенному)

**9 конституционных законов (текущая редакция):**
о Президенте (prezident), о Парламенте и статусе депутатов (parlament), о судебной
системе и статусе судей (sudsystema), о выборах (vybory), о Конституционном Суде
(konstsud), о государственных символах (gossimvoly), о республиканском референдуме
(referendum), о статусе столицы (stolitsa), о специальном правовом режиме города
Алатау (alatau). *(«О Правительстве» отложен — на adilet старый формат 1995 г.,
номер статьи в гиперссылке; ждём свежую выгрузку.)*

- **Линковка:** покрытие cov_real **медиана 97.1%**; внутренние ссылки — **0 WRONG,
  0 BROKEN** по всем 9 (каждая «статья N» резолвится в свою статью N; независимая
  проверка из сырого HTML). **full-span + text-invariance — PASS.**
- **konstsud:** 16 ранее-безякорных статей (заголовки `<h3>Статья N.` без `id`)
  **заякорены** аддитивно — теперь **все 67 статей** в слое и адресуемы cross-code.
- **Repealed — единый подход** по всем 43 докам корпуса (сноска «Статья N исключена»
  → `kind="repealed"`, **вне семантического индекса**).
- **Вектор-слой (43 дока): 20265 чанков** (9476 parent + 10575 subchunk + 214
  repealed), **665 summary** (выжимки крупных статей), faiss-индекс **17786 векторов**
  (MiniLM-384, repealed вне индекса). **Сирот 0.**
- **Ретрив (small-to-big):** hit@1 **17/28**, hit@3 **23/28**.

> **Примечание:** законы в переходном периоде под новую Конституцию (вступает
> 01.07.2026) — возможен рефреш отдельных актов после её вступления в силу.

## Структура пакета

```
anara_const_laws/
├── README.md                       — этот файл
├── codes/                          — 9 законов, форма _structured (КАНОН по ссылкам)
│   ├── prezident_structured.html   … (всего 9 .html)
├── chunks/                         — вектор-слой (для инженера/проверки)
│   ├── chunks.jsonl                — ВСЕ 43 дока корпуса: parent/subchunk/repealed + summary
│   ├── index_meta.jsonl            — какой вектор → какой чанк (uid/код/статья/якорь)
│   └── index_config.json           — модель/размерность/метрика индекса
└── reports/                        — отчёты-доказательства
    ├── const_laws_metrics.md       — по 9: статей, cov_real %, OK/WRONG/BROKEN, full-span,
    │                                 text-invariance, repealed, чанки, сирот, гейты
    ├── repealed_uniformity.md      — единый подход к repealed по всем 43 докам
    ├── retrieval_eval.md           — hit@1/hit@3, примеры запрос→статья
    └── summary_eval.md             — достоверность summary (числа/термины из оригинала)
```

## Расшифровка файлов

| файл | что значит | как читать |
|---|---|---|
| `codes/*_structured.html` | финальные размеченные законы (ссылки + якоря + иерархия) | открыть в **браузере** (не в Word — там ссылки визуально не видны) |
| `chunks/chunks.jsonl` | строка = чанк: `kind` (parent/subchunk/repealed), `text`, `summary`, `anchor`, `uid` | для vector DB; repealed-строки — вне эмбед-индекса |
| `chunks/index_meta.jsonl` | сопоставление позиции вектора faiss → родительская статья | справочно |
| `reports/const_laws_metrics.md` | сводные метрики по 9 — **главная таблица** | cov_real, WRONG=0/BROKEN=0, гейты PASS, konstsud-фикс |
| `reports/repealed_uniformity.md` | как помечены исключённые статьи (единообразно, 43 дока) | таблица + верификация |
| `reports/retrieval_eval.md` | качество семантического поиска | hit@1/hit@3 + примеры |
| `reports/summary_eval.md` | проверка, что summary не выдуманы (числа/термины из оригинала) | заземлённость ~94% |

## Заметки для ревью

- Смотреть ссылки **в браузере**: жёлтое в Word ≠ «не залинковано».
- cross-code на статьи других актов и внешние акты на несогласуемый якорь → **корень**
  документа (§4 — безопасный дефолт).
- prezident / referendum cov_real ниже (75–79%) — малые законы 1995 г. (больше
  генерик-отсылок «законодательством РК»), не дефект разметки; WRONG=0/BROKEN=0.
