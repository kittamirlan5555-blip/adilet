# ADILETkz — пакет batch 9 (для Анары)

Самодостаточный пакет по **9 новым кодексам**, добавленным в корпус. Всё проверено
независимо из сырого HTML (не только гейтами). Дата сборки: 2026-06-20.

## Что сделано (headline, по факту проверенному)

**9 новых кодексов добавлено в корпус:**
лесной (lesnoy), водный (vodniy), о здоровье народа (zdorovyenaroda), о браке и
семье (oBrake), таможенный (tamozhenniy), о недрах (oNedrah), строительный
(stroitelniy), цифровой (cifrovoy), уголовно-исполнительный (UIK).

- **Ссылки:** покрытие cov_real **медиана 98.4%**; внутренние ссылки — **0 WRONG,
  0 BROKEN** по всем 9 (каждая «статья N» резолвится в свою статью N; независимая
  проверка из сырого HTML).
- **Оригинальные ссылки adilet проверены — 0 потерь в теле.** Само-ссылки источника
  целы на **98.9%** (остаток — иная схема якорей adilet, §9: статьи достижимы под
  нашими якорями). Сносочные/правочные ссылки сняты намеренно по ТЗ-02. Ссылки
  сайдбара adilet («связанные документы», хром) исключены — не правовой текст.
- **Repealed: единый подход по всем 34 докам.** 188 сносок «Статья N исключена»
  помечены `kind="repealed"`, в семантический индекс **не входят (0)**. Полностью
  удалённые статьи (пропуски нумерации) — только в `repealed_gaps`.
- **Вектор-слой (34 дока): 19194 чанка** = 8928 parent (на статью, id = якорь zX)
  + 10078 subchunk (zX_N, ≤окна эмбеддера) + 188 repealed. **630 summary** (краткие
  выжимки крупных статей для поиска). Индекс faiss — **16856 векторов** (MiniLM-384,
  repealed вне индекса). **Сирот 0**, якоря целы.
- **Ретрив (small-to-big, 34 дока):** hit@1 **17/28**, hit@3 **23/28**.

## Расшифровка файлов

| файл | что значит | как читать |
|---|---|---|
| `codes/*_structured.html` | финальные размеченные документы (ссылки + якоря + иерархия) | открыть в **браузере** (не в Word — там ссылки визуально не видны) |
| `chunks/chunks.jsonl` | строка = чанк: `kind` (parent/subchunk/repealed), `text`, `summary`, `anchor`, `uid` | для загрузки в vector DB; reпealed-строки — вне эмбед-индекса |
| `chunks/index_meta.jsonl` | сопоставление позиции вектора в faiss → родительская статья | справочно |
| `reports/new9_metrics.md` | сводные метрики по 9 — **главная таблица** | cov_real, WRONG=0/BROKEN=0, гейты PASS |
| `reports/original_links_audit.md` | доказательство, что мы НЕ потеряли ссылки adilet в теле | раздел «Вердикт аудитора» внизу |
| `reports/repealed_uniformity.md` | как помечены исключённые статьи (единообразно) | таблица по докам + верификация |
| `reports/retrieval_eval.md` | качество семантического поиска | hit@1/hit@3 + примеры |
| `reports/summary_eval.md` | проверка, что summary не выдуманы (числа/термины из оригинала) | 501 чисто / 129 с мелкими замечаниями |
