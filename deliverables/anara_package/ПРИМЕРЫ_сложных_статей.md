## 2. УПК ст.32 — особый формат `<br/>` (не `<p>`)

**Чем сложна:** В УПК статьи структурированы НЕ через `<p>` теги (как в остальных кодексах), а через `<a id="zN"></a>1. Текст<br/>2. Текст<br/>...`. Без правила R12 (UPK-special, разделение по `<br/>`) вся статья ушла бы одним сплошным чанком. Правило корректно разрезает на 6 частей. Также `unit_type=часть` (не пункт) — согласно правилу R3 для УК/УПК.

**Фрагмент дерева:**

```
article=32, title="Дела частного, частно-публичного и публичного преследования и обвинения", status=active, unit_type=часть, children=6
  ├─ часть 1 (anchor=z193): подпунктов=0, продолжений=0
  ├─ часть 2 (anchor=None): подпунктов=0, продолжений=0
  ├─ часть 3 (anchor=None): подпунктов=0, продолжений=0
  ├─ часть 4 (anchor=None): подпунктов=0, продолжений=0
  ├─ часть 5 (anchor=None): подпунктов=0, продолжений=0
  ├─ часть 6 (anchor=None): подпунктов=0, продолжений=1
```
