# ТЗ-01 для рук (GPT / Claude Code): нормализация целей ссылок

**Приоритет: ПЕРВЫЙ.** Детерминированно, низкий риск, чинит главную претензию «внутренние ссылки не работают» + включает подсветку после перехода. Делать ДО трима over-linking и ручной сверки.

## Контекст (факты, проверены на socialnyy_structured.html)
В готовых файлах `data/final/<code>_{ready,structured}.html` ссылки на статьи оформлены **абсолютными URL**, а не локальными якорями:
- На СВОЙ же кодекс: `<a href="https://adilet.zan.kz/rus/docs/K2300000224#z1845">статьей 133</a>` — хотя `K2300000224` это сам соц.кодекс. Клик уводит на сайт адилета вместо прыжка внутри документа. Таких **553** в одном соц.кодексе.
- Часть ссылок указывает на внутренний сервер `http://85.202.192.66:9096/...` (**500** штук) — для ЕК/публики не откроются.
- Якоря-цели УЖЕ существуют: `id="zN"` (3462 шт.) и `name="zN"` (359). Ремапить id НЕ нужно.
- `06_finalize.py` подсвечивает цель через JS по `#hash` (`highlightTarget`) — **работает только если ссылка локальная `#zN`**, а не абсолютный URL. Поэтому сейчас подсветка не срабатывает.

## Что сделать
Написать скрипт `scripts/17_normalize_link_targets.py`, который для заданного кода правит его `data/final/<code>_ready.html` и `_structured.html`:

1. **Внутренние (свой doc_id) → локальный якорь.**
   Любой `href` вида `http(s)://(adilet.zan.kz|85.202.192.66:9096)/rus/docs/<OWN_doc_id>#zN` → заменить на `#zN`.
   - `<OWN_doc_id>` = doc_id текущего кода (плюс его deprecated-варианты).
   - Перед заменой проверить, что в этом же файле есть `id="zN"` или `name="zN"`. Если цели нет — НЕ локализовать, занести в отчёт `missing_anchor`.

2. **Внешние на внутренний сервер → публичный адилет.**
   Оставшиеся `http://85.202.192.66:9096` → `https://adilet.zan.kz` (хост, путь и `#zN` не трогать).

3. **Не трогать:** `javascript:`, `mailto:`, `http(s)://...advices.adilet...`, и ссылки на ЧУЖИЕ doc_id (это легитимные внешние ссылки — кроме правки хоста из п.2).

## Edge cases
- href может быть в одинарных или двойных кавычках; с/без `rus/` или `kaz/`; с query (`?...`) перед `#`.
- Один `<a>` = один href; вложенные `<a>` тут не создаём (их чистит скрипт 13).
- Идемпотентность: повторный прогон ничего не ломает (локальные `#zN` уже не матчатся правилом 1).

## Валидация (вывести в конце)
- сколько href локализовано (правило 1) по каждому коду;
- сколько хостов переписано (правило 2);
- список `missing_anchor` (href на свой код, но якоря нет) — это кандидаты в ручную правку;
- после прогона: `grep -c 'href="#z'` должно стать > 0; `grep -c '85.202.192.66'` должно стать 0.

## Критерий приёмки
Открыть `socialnyy_structured.html` в браузере, кликнуть внутреннюю ссылку «статьей 245» → страница **прыгает к ст. 245 внутри документа** и цель **подсвечивается** (highlight-target). Ни одной ссылки на `85.202.192.66`.
