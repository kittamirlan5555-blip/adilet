# data/ — содержимое подпапок

13 кодексов. Канон по ссылкам — `final/*_structured.html`; `_ready` подтягивается
из него, чанки/дерево пересобираются из него. Поток данных см. в корневом
`README.md`, раздел 2.

| Папка | Что внутри | Кол-во | Происхождение |
|---|---|---|---|
| `source/` | **исходный HTML** с adilet.zan.kz | 13 | скачано вручную; **read-only, не редактируется** |
| `final/` | `{code}_ready.html` (плоский со ссылками) + `{code}_structured.html` (+ иерархия) | 13 + 13 | Фаза A/B конвейера |
| `chunks/` | `{code}.jsonl` — строка = чанк (пункт + продолжения + подпункты) | 13 | `chunk_npa.py` из `_structured` |
| `tree/` | `{code}.json` — дерево статья→пункт→подпункт | 13 | `chunk_npa.py` из `_structured` |
| `maps/` | `article_map_{code}.json` (статья→якорь) + `subpoint_map_{code}.json` | 12 + 12 | `01_`/`07_`; вход для `02_`/`10_` |
| `reports/` | отчёты аудита/диффа/ревью + **`ОТЧЁТ_гиперссылки.md`** (для шефа) | ~74 | скрипты аудита; служебные `_*.txt` — рабочие |

## Якорная модель

* Якоря: `id="zN"` (иногда `name="zN"`) на заголовках статей/пунктов.
* Внутренние ссылки: `href="#zN"`. Обёртки иерархии получают `id="w_zN"`.
* `_ready` — плоский `<article>`: нет `div.document`, `div[data-type]`,
  `-label`-span. Видимый текст `_ready` == `_structured`.

пересоздавать прогоном соответствующего скрипта.

## Бэкапы

Все исторические бэкапы (`final_backup_*`), промежуточные (`interm/`,
`final_interim_*`) перенесены в `../archive/data_backups/` при уборке. Активный
конвейер их не читает (кроме строгих аудитов `audit_TZ0*`, которые диффят против
`archive/data_backups/final_backup_TZ0*`).
