# HANDOFF — ADILETkz

Этот файл — для человека, который принимает проект. За 10 минут даёт: что это, где
что лежит, в каком состоянии, какие правила нельзя нарушать и как продолжать.
Технику пайплайна см. [pipeline_logic.md](pipeline_logic.md). Жёсткие правила
агента — `../CLAUDE.md`. Кто чего ждёт — `../reports/WAITING_ON_HUMANS.md`.

## 1. Что это и зачем

Берём сырой HTML кодексов и законов РК с **adilet.zan.kz** и превращаем правовые
отсылки внутри текста («пунктом 2 статьи 35», «Законом РК "О банках…"», «статьёй 100
настоящего Кодекса») в рабочие гиперссылки. Два потребителя:
1. **adilet.kz** — публикация размеченных документов.
2. **Vector DB** — семантический поиск по корпусу (чанки + faiss-индекс).

Результат по каждому документу — `final/{слаг}_ready.html` (плоская форма) и
`final/{слаг}_structured.html` (иерархия, **КАНОН по ссылкам**).

## 4. Железные правила (нарушишь — сломаешь корпус)

1. **Полный спан.** Правовая ссылка = ОДИН непрерывный `<a>` на ВСЮ фразу, не на
   первое слово. `<a>пунктом 2 статьи 35</a>`, не `<a>пунктом 2</a> статьи 35`.
2. **Видимый текст не меняется.** Любая правка двигает только границы `<a>`.
   Гейт text-invariance: `get_text()` (без разделителя, ws-stripped) ДО == ПОСЛЕ.
3. **Якоря статей `zX` НЕ меняются** никогда. id сабчанков только ДОБАВЛЯЮТСЯ (`zX_1`…).
4. **Куда ведут ссылки:**
   - внутренняя («статьёй 100 настоящего Кодекса») → `#zX` в этом же файле;
   - внешний акт целиком («Законом РК "О банках…"») → **КОРЕНЬ** `…/docs/{НГР}` (без #z);
   - cross-code на статью → якорь статьи в целевом кодексе ИЛИ корень, если якорь
     не совпадёт с целевой средой (§9, ниже).
5. **Repealed единообразно:** сноска «Статья N исключена» → `kind="repealed"`,
   в семантический индекс НЕ входит. Полностью удалённые (пропуски нумерации) → только
   в `repealed_gaps`.
6. **Сноски/примечания не линкуем** (ТЗ-02): ссылки внутри `p.note`/`span.note`/
   «Примечание»/ИЗПИ-РЦПИ снимаются (`18_strip_links_in_notes`).
7. **`_structured` — канон.** `_ready` синхронизируется с ним (гейт G6).
8. **Слово Анары — закон.** Её жёлтое = ссылка, любое внутреннее правило отменяется.

## 5. Грабли, политые кровью

- **Гейты слепы к КОРРЕКТНОСТИ якорей.** `verify` скажет «зелено», когда ссылка ведёт
  на ЧУЖУЮ статью. Мислинки ловятся только независимой проверкой из сырого HTML
  (см. `original_links_audit.py`, `78_crosscode_root`). Не доверять «готово» от раннера.
- **§9 — наши якоря ≠ якоря ЖИВОГО adilet.** Наша выгрузка нумерует якоря по-своему;
  adilet-исходник ссылается на свои. Поэтому cross-code/само-ссылки источника на
  несогласуемый якорь → **корень** (безопасный дефолт). Открытый вопрос к Ергали:
  какая модель деплоя (наши файлы на adilet vs ссылки на существующие страницы adilet).
- **`npa_mapping.json` местами протух.** Перед линковкой проверять, что НГР —
  действующая редакция (§5 CLAUDE.md). Repeal-replace ремапы: налог
  K1700000120→K2500000214, бюджет K080000095_→K2500000171, банки Z950002444_→Z2600000258.
- **Ежегодный закон «о республиканском бюджете» (`Z2500000239`)** — обновлять НГР
  КАЖДЫЙ декабрь во всех документах.

## 6. Как продолжать

**Один новый документ** — см. README «Типовые сценарии» и [pipeline_logic.md](pipeline_logic.md).

**Батч (как batch9):**
1. `pre-flight`: `python scripts/audit/preflight_new.py <слаг…>` — структура парсится
   как у рабочих? doc_id извлечён? Кривые — не гнать.
2. Удалить `source/*_files` (ассеты браузера).
3. Зарегистрировать слаги в `maps/codes.json` (doc_id) + `maps/doc_codes.json`
   (hier/label, без коллизий).
4. Прогон: `pipeline.py` → `11_structure_html` → `68_link_canon` (обе формы) →
   `71_fullspan_wrap` → `79_canon_self_anchor` (если G6) → `chunk_npa`.
5. `verify.py --all` — GREEN.
6. Метрики → `reports/{batch}_metrics.md` (таблица как в `new9_metrics.md`).
7. Аудит оригинальных ссылок: `python scripts/audit/original_links_audit.py`.
8. Вектор-слой (по отдельной команде): `f_full_chunks` → `c_summarize` (DeepSeek,
   сначала число+цена) → `g_build_index` → `i_retrieval_eval`.
9. Пакет для Анары → `deliverables/{batch}/` + zip. Коммит, пуш по команде.
