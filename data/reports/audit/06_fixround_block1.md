## Виновник порчи (Блок 1.4)

**`scripts/02_fix_internal_links.py`** (и его копия `law_kit/scripts/02_…`), блоки
пересборки перечней «пунктами N и M / подпунктах N), M) настоящей статьи»:
скрипт НЕ оборачивает ссылки in-place, а ПЕРЕСОБИРАЕТ видимый текст из частей.
Регекс сепаратора `(?:\s*,\s*|\s+-\s*|\s+и\s+)` знает только ДЕФИС, не «–»/«—»:
на «пунктами 2 – 5» сепаратор не матчится и срабатывает молчаливый фолбэк:

```
строка 602:  sep = sep_m.group(1) if sep_m else ' и '
строки 402/542/698/735/776/1004:  …else ', '
```

— диапазон «2 – 5» становится «2 и 5», «1) – 4)» становится «1), 4)».
Датировка по бэкапам: порча уже в `data/final_backup_ANARA_RECHECK` (старейший
доступный byudzhet) — внесена ранним пайплайном, не ручными раундами.

**Принято:** в оба файла добавлен баннер DO-NOT-RUN + рантайм-гард
(`raise SystemExit`, снимается только `ALLOW_TEXT_REWRITE=1`). Оба файла §11-
исключены из публичной ветки (внутренний IP в дефолтах) — маркировка локальная,
этот отчёт — публичная фиксация. Чинить: оборачивать in-place + гейт
text-invariance, после чего снять гард.
