## Типы проблемы
- INTERNAL_LINK_MISSING_ARTICLE — отсутствует внутренняя ссылка на «статью N настоящего Кодекса».
- INTERNAL_LINK_MISSING_SELFREF — отсутствует внутренняя ссылка на «N настоящей статьи / пункт настоящей статьи / часть N настоящей статьи».
- INTERNAL_LINK_MISSING_SECTION_OR_PARAGRAPH — отсутствует внутренняя ссылка на «параграфом / разделом / главой … настоящего Кодекса».
- INTERNAL_LINK_MISSING_LIST — список из множества статей внутри `(статьями A, B, C ...)` не кликабельные.
- EXTERNAL_LINK_MISSING_CROSSCODE — отсутствует cross-code ссылка на другой кодекс РК.
- EXTERNAL_LINK_MISSING_LAW — отсутствует ссылка на внешний закон РК.
- TOO_MUCH_TEXT_LINKED — слишком большой фрагмент текста стал ссылкой (захвачено лишнее).
- ARTICLE_TITLE_NOT_BOLD — заголовок статьи не отформатирован как у других статей (структура сбилась).
- REGRESSION — целиком кодекс регрессировал относительно предыдущей версии.
- UNKNOWN — нужна ручная классификация.
